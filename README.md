# 🍩 Luttan Donuts

# 

# \## ¿Qué es?

# 

# En este proyecto estamos creando una página web para \*\*Luttan Donuts\*\*, una tienda de donas

# 

# En la página mostramos información sobre el negocio, sus productos y sus medios de contacto. También contamos con diferentes secciones para que el administrador y los empleados puedan realizar algunas funciones del negocio

# 

# \## ¿Qué podemos encontrar en la página?

# 

# \*  Inicio

# \*  Productos

# \*  Inventario

# \*  Ventas y caja

# \*  Gastos

# \*  Empleados

# \*  Reportes

# \*  Cierre de caja

# \*  Nosotros

# \*  Contacto

# 

# Para realizar este proyecto estamos utilizando \*\*HTML, CSS, Java y MySQL\*\*. También usamos \*\*Git y GitHub\*\* para trabajar en equipo, organizar el proyecto y guardar los cambios que vamos realizando
